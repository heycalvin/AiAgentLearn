# 第1章 Agent基础知识

![第1章配图](../../assets/ai-agent-book-illustrations/01-chapter1.png)

## 先看结论

这一章最重要的一句话是：

`Agent = LLM + 上下文 + 工具`

你可以把它理解成：

- `LLM` 负责思考
- `上下文` 负责看清情况
- `工具` 负责真正做事

所以，Agent 不是一个只会聊天的模型，而是一个能想、能看、能做的系统。

## 什么是 Agent

普通聊天机器人常常是这样：

你问一句，它答一句。

Agent 不一样。它会先想一想，再决定下一步要做什么。它可能会：

1. 读懂你的目标
2. 拆成几个小步骤
3. 调用工具去执行
4. 看结果，再继续下一步

这就是 Agent 的核心特点。

## 三个核心部分

### 1. LLM：大脑

LLM 就是模型的思考部分。

它负责：

- 理解你的意思
- 做判断
- 生成回答
- 决定下一步动作

你可以把它想成“会思考的脑子”。

### 2. 上下文：眼睛

上下文就是模型当前能看到的信息。

它包括：

- 你的问题
- 之前的对话
- 当前任务状态
- 记忆
- 外部资料

上下文越清楚，Agent 越容易做对。

### 3. 工具：手脚

工具就是让 Agent 能做事的能力。

比如：

- 搜索网页
- 读写文件
- 调接口
- 执行代码
- 发消息

没有工具，Agent 只能说；有了工具，它才能真的行动。

## 一个简单例子

比如你说：

“帮我订一张下周去上海的机票。”

Agent 可能会这样做：

1. 先确认日期和出发地
2. 看当前能找到哪些航班
3. 比较价格和时间
4. 把结果整理给你
5. 如果你确认，它再继续下一步

你会发现，它不是一次性输出答案，而是在一步一步完成任务。

## 什么是 ReAct

ReAct 可以简单理解成：

**先想，再做，做完再看结果，然后继续想。**

这是很多 Agent 的基本运行方式。

它很像人做事的习惯：

- 先想办法
- 再动手
- 看到结果后再调整

## 什么是 Harness

书里还强调一个很重要的词：`Harness`。

你可以把 Harness 理解成“外壳”“控制层”或者“任务执行框架”。

它不是模型本身，但它很重要，因为它负责：

- 组织上下文
- 管理工具
- 检查结果
- 处理失败
- 加安全限制

也就是说，模型负责“会不会想”，Harness 负责“能不能稳稳地做成”。

## 为什么这章重要

这一章是全书的底座。

如果你只记住一件事，那就是：

**一个好的 Agent，不是单靠更强的模型，而是模型、上下文、工具一起配合。**

## 记住一句话

Agent 的本质，不是“回答问题”，而是“完成任务”。
