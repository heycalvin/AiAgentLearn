# 03. 给 Agent 装上记事本：记忆系统与知识库 RAG

> **导读**：人的注意力一次只能看几页纸，大模型也是一样。当对话越来越长、资料堆积如山时，Agent 是怎么做到“过目不忘”的？

---

## 🧠 1. Agent 记忆的两个“抽屉”

```mermaid
graph TD
    UserQuery[用户提出问题 / 任务] --> WorkingMemory[📝 抽屉 1: 短期工作记忆<br/>(当前正在聊天的这几轮对话)]
    UserQuery --> LongTermMemory[🗄️ 抽屉 2: 长期知识库 RAG<br/>(过去所有的历史偏好 / 公司万页文档)]
    
    WorkingMemory --> Brain[🧠 大脑 LLM]
    LongTermMemory -->|检索出最相关的几段话| Brain
    Brain --> Answer[给出准确回答]
```

### 抽屉 1：短期工作记忆（便签纸）
- **特点**：放在眼皮底下，随看随用，但空间很小（受限于模型的 Context Window 上下文窗口）；
- **用途**：记录刚刚那一轮工具返回的报错、当前做到了哪一步。

### 抽屉 2：长期知识库 RAG（图书馆与档案袋）
- **特点**：存在硬盘或外部数据库中，容量无限大，但不能全部塞给大模型看；
- **用途**：当你说“查一下我们公司去年的差旅报销制度”，Agent 去图书馆里翻出**最相关的 3 段话**，夹在便签纸上递给大模型。

## 🔍 2. 什么是 RAG？（开卷考试模式）

- **不带 RAG（闭卷考试）**：大模型只能靠训练时记住的固定知识。如果问它“张三昨天的考勤记录”，它只能瞎猜或者说不知道。
- **带 RAG（开卷考试）**：
  1. **先搜资料**：在企业数据库里精准找到张三昨天的打卡日志；
  2. **带入考场**：把打卡日志放进当前提示词里；
  3. **模型归纳**：大模型看着真实日志生成结论给你。

---

## 🌲 3. 什么是会话树（Session Tree）？（允许后悔的时光机）

如果 Agent 在解决某个难题时走进了死胡同（比如尝试了一种重构方案改崩了代码），普通聊天只能一条道走到黑。  
而在高级 Agent 系统中，支持**会话树回退**：
- 记录每一个关键分叉点；
- 发现路线 A 走不通，Agent 可以**一键回退到 10 分钟前的状态**，换路线 B 重新再试。
