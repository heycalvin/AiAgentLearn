# AI Agent Book Notes

This repo contains simple, beginner-friendly notes for the book **AI Agents in Depth**.

The goal is not to copy the book. The goal is to help you understand it in plain words, one chapter at a time.

## Source

- Original book site: [https://bojieli.github.io/ai-agent-book/](https://bojieli.github.io/ai-agent-book/)
- GitHub repository: [bojieli/ai-agent-book](https://github.com/bojieli/ai-agent-book)

## What this Git repository does

This folder is a Git repository.

Git keeps track of file changes over time. That means you can:

- see what changed
- compare different versions
- go back to an older version if needed
- work on the same project in a safer way

## How to read

1. Start with the book notes in `book/`.
2. Read one chapter at a time.
3. Use the short examples to connect the ideas to real life.
