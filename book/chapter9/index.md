# 第9章 多模态与实时交互

## 先看结论

这一章讲的是：**Agent 不只会看文字，还要会听、会看、会说，而且要能实时反应。**

这会让 Agent 更接近真实世界里的工作方式。

## 什么是多模态

多模态就是处理多种输入。

除了文字，还可能有：

- 语音
- 图片
- 视频
- 传感器信息

现实世界里的信息本来就不是只有文字，所以 Agent 也不能只靠文字。

## 为什么多模态很重要

很多任务不是纯文本问题。

比如：

- 看图识别内容
- 听语音做笔记
- 读屏幕做操作
- 看视频分析流程

如果 Agent 只会文字，它就会丢掉很多关键信息。

## 语音 Agent

语音 Agent 是这一章里很重要的一类。

它要做的不只是“把语音转成字”。

它还要：

- 理解语气和上下文
- 快速反应
- 支持打断
- 支持流式输出

这会让对话更自然。

## 实时交互

实时交互的重点是“快”和“连续”。

真实场景里，用户不会一直等模型想完。

所以系统要支持：

- 边听边想
- 边想边说
- 用户插话时能及时停下
- 任务状态要跟着变化

这比普通聊天难很多。

## Computer Use

这一章还讲了 `Computer Use`。

你可以把它理解成：

**让 Agent 像人一样操作电脑界面。**

它可能要看屏幕、找按钮、点击、输入、切换窗口。

这类任务很像真实办公场景。

## 机器人操作

更进一步，Agent 还可以连接到机器人。

这时候它面对的不只是屏幕，而是真实环境。

比如：

- 移动
- 抓取
- 识别物体
- 处理动作反馈

这类场景对安全和实时性要求更高。

## 这一章的难点

多模态和实时交互很强，但也很难。

主要难点包括：

- 延迟不能太高
- 输入类型很多
- 输出要及时
- 失败时要安全
- 中途变化要能处理

这不只是模型问题，也是系统问题。

## 一个简单例子

你对着语音 Agent 说：

“帮我看一下这张图，然后把重点发给我。”

它要先理解图片，再组织语言，再尽快回复你。

如果你中途又补一句，它还要能跟上。

## 这一章最想告诉你什么

Agent 的未来不只是文字聊天。

它会越来越像一个能感知环境、快速反应、和现实世界互动的助手。

## 记住一句话

多模态让 Agent 看得更多，实时交互让 Agent 反应更像人。
